COACHME — MISE EN LIGNE GRATUITE

CONTENU
- index.html : page de l’application
- style.css : styles et adaptation mobile
- app.js : fonctionnalités CoachMe
- manifest.webmanifest + service-worker.js + pwa.js : installation PWA et cache hors ligne
- icons/ : icônes de l’application

PUBLICATION AVEC GITHUB PAGES
1. Connecte-toi à GitHub et crée un nouveau dépôt public (ex. coachme).
2. Dans le dépôt, clique sur Add file > Upload files.
3. Dépose TOUS les fichiers et le dossier icons contenus dans ce dossier. Il faut que index.html soit à la racine du dépôt.
4. Valide avec Commit changes.
5. Ouvre Settings > Pages.
6. Dans Build and deployment, choisis Deploy from a branch, branche main, dossier /(root), puis Save.
7. Attends la publication. GitHub affichera une adresse du type https://TON-PSEUDO.github.io/coachme/ .
8. Ouvre cette adresse sur ton téléphone.

INSTALLATION
- Android : Chrome > menu ⋮ > Installer l’application ou Ajouter à l’écran d’accueil.
- iPhone : Safari > Partager > Sur l’écran d’accueil.

IMPORTANT
- L’installation PWA et le mode hors ligne nécessitent une adresse HTTPS (GitHub Pages fournit HTTPS).
- Les données CoachMe restent enregistrées localement sur chaque navigateur/appareil. Exporter/importer le fichier JSON ne synchronise pas automatiquement les appareils.
- Fais une sauvegarde JSON avant de remplacer ou importer des données.
- Ne mets pas de vraies informations personnelles de joueurs mineurs en ligne pour un premier test ; utilise des données fictives.
